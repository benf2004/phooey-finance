# Phooey design system

## User-directed revision — November 12, 2026

Mode: redesign / overhaul of presentation. Preserve routes, data, validation, keyboard access, authentication and all financial calculations.

The user rejected the editorial voice, custom typography, generous spacing and repetitive explanatory copy. The app is a compact financial workspace, not a marketing page. Use direct nouns for titles and actions. Remove slogans, eyebrows, captions that repeat headings, decorative status claims and generic reassurance. Keep explanations only when they affect an input or interpretation; put longer tax assumptions behind disclosure controls.

Design read: individual finance dashboard, laptop-first analysis with mobile review. Visual variance 2, motion 1, information density 9, asset dependence 1, brand fidelity 3. Stable grids and tables; no decorative imagery. Narrative role is operational data, viewed at laptop distance, with a quiet neutral tone. Capacity is measured in useful rows and values per viewport.

Typography: native system sans-serif for intentional platform neutrality; 13px desktop controls and tables, 22px page titles, 14px section titles, tabular financial numbers. No downloaded display fonts. Neutral gray surfaces (#F7F8FA), white panels, ink #20252B, muted #65717D, borders #E1E5EA. Green #28634A is reserved for primary actions and financial meaning. Dark mode uses neutral equivalent surfaces.

Spacing: 4px base; 12–16px section padding; 34px desktop controls; 44px primary touch controls. Borders group information; 6px panel radii; shadows only for floating surfaces. State transitions only, with reduced-motion support.

Taxes: Income & deductions is collapsed by default. Annual estimate and quarterly payment table are visible without opening the inputs. Rates, calculation details and limitations remain accessible. Invalid fields reopen the disclosure before browser validation. Preserve all necessary tax assumptions and source references.

Demo data remains explicitly labeled and is never loaded into production automatically. Preserve AGPL-3.0 and the source link.
