A few good questions

What’s included in the hosted plan?

Finance and Invoicer are included for $29 per year after a 14-day free trial. A card is required to start. Optional bank syncing has a separate subscription.

Can I try the dashboard before signing up?

Yes. Explore the interactive preview with sample transactions, accounts, categories, and reports. Changes in the preview only affect the example data in your browser.

Do I need to connect my bank?

No. Import a CSV or enter transactions yourself. Bank syncing is optional.

Can I invoice for more than one business?

Yes. Switch businesses in Invoicer’s sidebar. Each business has its own customers, branding, invoice numbering, and API keys.

Can an AI assistant work with my invoices?

Yes. Create a business-specific API key in Invoicer’s API & MCP page. Choose read-only or read-and-write access, and revoke it whenever you need.

Can I host it myself?

Yes. The source is on GitHub under AGPL-3.0. Self-hosting uses your own Cloudflare account and resources.
